# Demo VECTRA — 60–90 detik

Gunakan build lokal dengan fixture TEST_ONLY sampai alur konten produksi lolos gate. Label layar pembuka: **DEMO — DATA CONTOH, BUKAN HASIL SISWA**. Menyelesaikan diagnostic/practice/mini untuk demo dilakukan sebelum merekam; durasi 90 detik adalah presentasi hasil alur, bukan waktu mengerjakan semua soal.

| Detik | Layar / aksi                                | Narasi dan bukti                                                                                                                             |
| ----- | ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–10  | Landing → workspace                         | “VECTRA Math. Know Your Direction. Position → Direction → Progress.” Label data contoh tetap terlihat                                        |
| 10–25 | Hasil diagnostic → Progress                 | Tunjukkan jumlah jawaban dan soal unik per keterampilan. “Mastery dan confidence adalah indikator internal; bukan prediksi skor resmi UTBK.” |
| 25–40 | Home → Buka rekomendasi belajar             | Tunjukkan alasan berupa mastery, jumlah bukti dan ketersediaan alur; buka lesson terkait                                                     |
| 40–55 | Lesson terakhir → Continue to Practice      | Perlihatkan latihan yang benar-benar memuat subtopic sama; tunjukkan satu langkah pembahasan                                                 |
| 55–72 | Hasil Practice → Asesmen ulang keterampilan | Gunakan mini, bukan mengganti tujuan dengan tryout domain lain. Tunjukkan timer, hasil dan count soal yang pernah muncul                     |
| 72–90 | Progress → buka hasil sebelumnya            | Perlihatkan tiga riwayat dan hasil tersimpan. Penutup: “Alur ini teruji lokal. Pilot produksi menunggu konten dan acceptance.”               |
