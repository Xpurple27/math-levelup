# VECTRA demo script — 60–90 seconds

Use a **demo/test account** and label it visibly as demo data.

| Time | Screen | Narration / proof |
| --- | --- | --- |
| 0–10s | Landing + Diagnostic CTA | “VECTRA Math starts with Position: measure evidence before choosing what to study.” |
| 10–25s | Completed Diagnostic / Learning Profile | Show mastery, confidence and evidence count. State: “These are internal learning indicators, not an official UTBK score prediction.” |
| 25–40s | Next Direction → Learn | Open the recommended published lesson. Show concept, example/common mistake and connected checkpoint. |
| 40–55s | Final lesson → Practice | Use `Continue to Practice`; show that the related domain is selected and start one set. |
| 55–72s | Result / explanation → Assessment | Briefly show structured explanation, then open the Mini Tryout card and explain per-section timer authority. |
| 72–90s | Progress / history | Reopen a completed attempt from history. End on `Position → Direction → Progress ↗` and `Know Your Direction.` |

Do not insert fabricated testimonials, users, transactions, score gains, or production status into the recording.
