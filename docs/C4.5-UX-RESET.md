# C4.5 — UX Foundation Reset

## Goal

LevelUP Math must stop feeling like one internal dashboard used by every role. C4.5 separates the public site, student learning app, admin content studio, and reviewer workspace without rewriting the assessment/content engines.

## Product rules

- Public visitor, student, admin, and reviewer have different shells and different dominant tasks.
- Student UI uses top navigation on desktop and bottom navigation on mobile. It does not use the admin-style left sidebar.
- Admin keeps a dense content-operations sidebar.
- Reviewer gets a focused QA workspace and is redirected away from the admin studio.
- Exam mode removes normal student navigation to reduce distraction.
- Logout clears the active attempt reference and redirects out of the protected workspace.
- A completed diagnostic is not presented as if the student has never taken it. The primary action becomes viewing the ability profile; retake is secondary.
- Internal labels such as RC/QA status never become student marketing copy.

## Visual direction

**Modern Academic Energy**: warm paper base, deep red primary, restrained gold accent, charcoal typography. Avoid purple/blue AI gradients, equal-card feature rows, excessive pills, card-inside-card composition, and a single shell for all roles.

The redesign follows the audit discipline from Leonxlnx/taste-skill `redesign-existing-projects`: preserve the existing stack and behavior, improve typography/hierarchy/spacing/states, and avoid generic AI interface patterns.

## Routes introduced

- `/` public landing
- `/login` dedicated login
- `/register` dedicated registration
- `/app` authenticated student workspace
- `/admin` admin-only content studio
- `/reviewer` reviewer-only workspace
- `/reviewer/queue` reviewer QA queue

## Explicitly unchanged

- trusted scoring
- attempt snapshots
- timer/autosave/resume
- mastery engine
- question versioning
- QA decisions and publishing rules
- Excel import behavior
- Supabase role source of truth

## Acceptance checks

- unauthenticated visitor sees the public landing page rather than the student dashboard
- `/app` redirects an unauthenticated visitor to `/login`
- login routes ADMIN to `/admin`, REVIEWER to `/reviewer`, STUDENT to `/app`
- reviewer opening `/admin` is redirected to `/reviewer`
- student logout leaves the protected workspace
- completed diagnostic shows `Lihat profil kemampuan` as the primary action
- desktop student UI has no fixed left sidebar
- mobile student UI exposes bottom navigation
- exam mode hides normal student navigation
